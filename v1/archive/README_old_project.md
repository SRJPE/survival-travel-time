# srJPE survival and travel-time models (Phase 2 working copy)

Working copy of Flora Cordoleani's CJS / CWT / combined Stan pipeline, with the
Phase 2 fixes applied. See `CHANGES.md` for exactly what changed and why.

Open `20260820_flora_mortality.Rproj` in RStudio. All scripts run from the
project root (`source("scripts/...")`, `here()` paths).

## Layout

```
20260820_flora_mortality.Rproj   RStudio project (sets the working directory)
.here                            anchor for here::here()
README.md                        this file
CHANGES.md                       fixes applied, open items, rerun order
scripts/
  01_PrepData.R                  pull ERDDAP detections + SRJPEdata, build model tables   [patched]
  02_GetData.R                   build model data objects (sourced by 03-09)             [patched]
  03_Run_CJS_Model.R             CJS-only fits (CovIndCont run 15 = MaxFlow + FL)
  04_CJSModel_Diagnostic.R       convergence diagnostics for a CJS fit
  05_CJSModel_Predictions.R      CJS-only predictions, forecasts, figures                 [patched]
  06_Run_CWT_Model.R             CWT-only fit                                             [patched]
  07_CWTModelPredictions.R       CWT-only predictions and figures
  08_Compare_CWT_CJS_Predictions.R  CWT-only vs CJS-only comparison                       [patched]
  09_Run_Combined_CJS_CWT_Model.R   combined CJS + CWT fit                                [patched]
  helper_fxt.R                   ERDDAP / detection-history helpers                       [patched]
  extract_pcap_estimate.R        Knights Landing pCap prior helpers
  *.stan                         Stan models (unchanged)
  checks/check_A1_A2.R           alignment + flow-scale checks (should now pass)
data/                            inputs and intermediate tables

  tables/  figures/
```

## Copy these in from Flora's old folder before running

| File | Put it in | Used by |
|---|---|---|
| `FPTflow.csv` (Freeport flow, CDEC) | `data/` | 01 |
| `cdec-water-year-type-jun-2025.xlsx` | `data/` | 02 |
| `pCap_one_site_skew_re_knights landing.rds` | `results/` | 06, 09 (they now stop if it's missing) |

Everything else in `data/` is regenerated by `01_PrepData.R`, which re-pulls the
detection data from ERDDAP each run. ERDDAP and SRJPEdata may have changed since
Flora's fits, so small differences from her numbers are expected even before
the fixes.

## Packages

tidyverse, here, lubridate, readxl, ggpubr, rstan, bayesplot, posterior, loo,
rerddap, vroom, leaflet. RMark is optional (not used by the pipeline).
SRJPEdata: `remotes::install_github("SRJPE/SRJPEdata")`.

## Run order

`01` > `02` (sourced) > `scripts/checks/check_A1_A2.R` > `03` (run 15) > `04` >
`05` > `06` > `07` > `08` > `09`. Details in `CHANGES.md`.
