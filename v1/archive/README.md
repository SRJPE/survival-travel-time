# archive/

Scripts from the original analysis folder (Flora's code plus later model
comparisons and checks), copied on 19 Nov 2026 by `setup/archive_old_scripts.R`.
They are a record of how the production model was chosen, not runnable code:
paths point at the old folder layout, and data, results and fits are not included.

`INDEX.csv` lists each script with its date, its header comment and, where the
production pipeline replaced it, the script that did (`replaced_by`).

The production pipeline is `scripts/refit/` and `scripts/export/`; see `WORKFLOW.md`.
